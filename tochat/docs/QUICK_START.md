# OFFOR SAMPLE FORGE Quick Start

1. Launch `OFFOR SAMPLE FORGE.exe` with its `Resources` folder present.
2. Click **New**, choose a project location/name, then **Save**.
3. Click **Import Folder** and select a folder containing audio samples.
4. Open **Sample Library**, choose a sample, and press **Play Preview**.
5. Open **Processing**. Select an effect type, press **Add Effect**, select it in the chain, and adjust its labeled parameters.
6. Press **Render Processed Copy**. The source stays unchanged; play the original or processed copy to compare.
7. Open **Variations**, choose a count and intensity, then press **Generate Variations**. The default is five.
8. Lock any result to protect it. Select variation cards and choose **Export Selected** to copy WAV files.
9. Save the project. Use **Open** later to restore project state.

**Plugin note:** The **VST3 Plugins** page discovers installed VST3 metadata. This build does not load plugins or process audio through them. VST2 hosting and full source-sample pack export are unavailable.



## Keyboard controls and Quick Help

- **Ctrl+S** saves the current project.
- **Ctrl+O** opens a project.
- **Space** pauses or resumes the current audio preview.
- **Delete** requests confirmation before deleting selected unlocked variations.
- The **?** header button opens Quick Help. Hover over controls for further explanations.

Plugin scan results are labeled **Discovered**. This build does not load plugins, so a discovered name is not a hosted effect or instrument.
